# Fake News Detection System
ML model to classify news articles as Real or Fake.

## Tech Stack
Python | Scikit-learn | NLP | TF-IDF | Logistic Regression

## How to Run
pip install scikit-learn pandas numpy
python fake_news_detection.py

## Accuracy
87.50% on test data
